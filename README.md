# Тестирование BooksCollector

## Описание проекта

В проекте реализованы автотесты для класса `BooksCollector`.

Класс `BooksCollector` позволяет:
- добавлять книги;
- устанавливать жанры книг;
- получать информацию о книгах;
- формировать список книг для детей;
- добавлять и удалять книги из избранного.

Тесты написаны с использованием фреймворка **pytest**.

## Запуск тестов

Для запуска тестов необходимо выполнить команду:

```bash
pytest -v tests.py
```

## Покрытые тестами сценарии

Всего реализовано **10 автотестов**.

### Добавление книг
- проверка успешного добавления новой книги;
- проверка, что книга с названием длиннее 40 символов не добавляется.

### Работа с жанрами
- проверка установки жанра для существующей книги;
- проверка получения жанра книги;
- проверка получения списка книг с определённым жанром;
- проверка получения словаря книг с жанрами.

### Проверка книг для детей
- проверка, что книги с возрастным рейтингом не попадают в список детских книг;
- проверка, что книги без возрастного ограничения добавляются в список.

### Работа с избранным
- проверка добавления книги в избранное;
- проверка удаления книги из избранного;
- проверка получения списка избранных книг.
